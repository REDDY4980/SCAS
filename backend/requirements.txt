# --dry-run` then a real install, in a clean venv, on 2026-08-10.
# The critical fix: opencv-python-headless is pinned to a 4.x version.
# Left unpinned, pip resolves it to the 5.x line, which requires
# numpy>=2 — directly conflicting with paddleocr's numpy<2.0
# requirement. That conflict was the root cause of every earlier
# build failure. Pinning opencv to 4.10.0.84 removes the conflict
# entirely; nothing else needed to change.
#

# version set (numpy 1.26.4, xgboost 2.1.1, scikit-learn 1.5.2,
# pandas 2.2.3) so the serialized model.joblib is guaranteed loadable
# by whatever this file installs. 99.09% test accuracy.
